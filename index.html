Integrasi Sinkronisasi Cloud JSONBin.io

JSONBin.io memungkinkan biodata Anda disimpan di database cloud gratis sehingga siapapun di internet dapat melihat data secara realtime saat Anda update!

Panduan Gratis Cepat Dapatkan JSONBin Keys (1 Menit):
  1. Buka website jsonbin.io dan buat akun gratis.
  2. Masuk ke Dashboard & Click menu **API Keys** di sebelah kiri untuk menyalin **X-Master-Key**.
  3. Buat **New Bin** baru dengan isi JSON apa saja, lalu simpan untuk mendapatkan **Bin ID**.
  4. Masukkan kedua kode tersebut di bawah ini lalu klik **Tes & Simpan ke Cloud**.
